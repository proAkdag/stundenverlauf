# Stundenverlauf

Stundenverlauf für die Klasse als PWA: Eröffnung mit Material, Thema und Ablauf, Arbeitsphasen mit Zeitscheibe, Abschluss. Sechs Stunden je Tag lassen sich vorab planen.

Die App läuft nach dem ersten Laden ohne Internet. Alle Einträge bleiben im Speicher des Geräts, nichts wird gesendet.

Am iPad: in Safari öffnen, dann „Teilen“ → „Zum Home-Bildschirm“.
